# Cyber Bastion — Адаптивная статичная страница

Минималистичная статичная веб-страница для **Cyber Bastion**, разработанная строго по техническому заданию в корпоративном стиле.

---

## 1. Содержание страницы

Страница содержит **исключительно** 4 обязательных элемента ТЗ:

1. **Заголовок:**
   > «Организуйте командную работу в одном месте»
2. **Три шага:**
   - **01. Создайте команду** — Объедините участников в одном рабочем пространстве.
   - **02. Распределите задачи** — Назначьте ответственных, установите сроки и определите приоритеты.
   - **03. Контролируйте выполнение** — Отслеживайте статусы задач и следите за прогрессом команды.
3. **Кнопка действия:**
   - Текст: **«Начать работу»**
4. **Блок «Что вы получите»:**
   - **1. Порядок в задачах** — все задачи команды собраны в одном месте.
   - **2. Контроль процессов** — понятные статусы, сроки и ответственные.
   - **3. Эффективная работа** — удобная организация совместной деятельности.

Никаких лишних секций (хедеров, навигации, футеров, лишних карточек, иконок) нет.

---

## 2. Цветовая схема 60 / 30 / 10

Дизайн строго соблюдает пропорцию:

- **60% — Sand (`#EAE3D5`):** Доминирующий цвет страницы, фон верхних секций (Hero, шаги, CTA).
- **30% — Deep Blue (`#172A3A`):** Корпоративный темно-синий цвет для типографики, заголовков и фонового блока секции «Что вы получите».
- **10% — Gold (`#D6A84B`):** Акцентный золотой цвет для кнопки действия «Начать работу» и нумерации шагов (`01`, `02`, `03`) и преимуществ (`1.`, `2.`, `3.`).

Стиль: чистый корпоративный минимализм. Без градиентов, без декоративных теней, без сложных анимаций.

---

## 3. Технические параметры

- **HTML5 & CSS3:** Статичная страница, HTML и CSS вынесены в отдельные файлы (`index.html` и `css/style.css`).
- **Mobile First:** Сначала сверстана компактная мобильная версия (360px), затем добавлены медиа-запросы `min-width` для планшетов и десктопов (1440px).
- **Валидация W3C:** 0 ошибок, 0 предупреждений (проверено через официальный сервис W3C Nu HTML Checker).
- **Шрифты:** Локальные файлы гарнитуры Manrope (`.woff2`, `.ttf`) подключены через директиву `@font-face` из папки `fonts/` с системным fallback (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`). Никаких внешних ссылок и Google Fonts CDN.
- **Без JavaScript:** 0 строк JS, отсутствие атрибутов `onclick`/`onload`, inline-скриптов и внешних библиотек.
- **Без inline-стилей:** Атрибут `style` не используется.
- **Отсутствие горизонтального скролла:** Проверено при 360px и 1440px.
